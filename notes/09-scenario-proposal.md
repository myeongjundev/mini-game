# 시나리오 제안 — 야간 당직

**2026-08-21 결정: A만 넣습니다.** 최소 규모(인수인계서)를 구현했고 명세는
`docs/GAME_SPEC.md` 15절로 옮겼습니다. 말투는 사무적인 존댓말에 사람 말투를
섞는 쪽(9절 2번 물음)으로 정했습니다.

**B와 C는 넣지 않았습니다.** 이유는 10절에 있습니다.

아래는 결정의 근거로 남겨둔 원래 제안입니다.

**2차 개정.** 1차는 "내부자를 찾아내는" 수사물이었습니다. 버렸습니다.
이유는 8절에 있습니다.

## 1. 이미 노동 시뮬인데 결과 화면만 아케이드입니다

게임을 다시 봤습니다. 30초 동안 하는 일이 이겁니다.

- 새벽 2시에 혼자 앉아 있습니다
- 부서들이 공지를 보냅니다. 마케팅, IT, 보안, 인프라, 인사
- 상사가 전화해서 "그거 통과시켜"라고 합니다
- 경보가 3초에 하나씩 옵니다. 다 봐야 합니다

**이건 전부 노동입니다.** 사건이 아니라 일이에요.

그런데 근무가 끝나면 이렇게 뜹니다.

```
SCORE      5,400
MAX COMBO  ×14
```

**콤보.** 관제 분석가에게 콤보가 어디 있습니까. 게임의 내용은 미생인데
결과 화면만 아케이드 오락실입니다. 여기가 어긋나 있습니다.

그래서 새 기능을 붙이는 게 아니라 **이미 하고 있는 일을 제대로 보여주는**
쪽으로 갑니다.

## 2. 제안 A — 결과 화면을 인수인계서로

`SHIFT REPORT / SECURITY LOST` 대신, **다음 근무자에게 넘기는 문서**입니다.
지금 있는 값으로 문장을 만듭니다. 새 데이터가 필요 없습니다.

무난한 밤:

```
INCIDENT HANDOVER
02:00 – 02:30  ·  야간 당직

경보 10건 검토. 놓친 것 없음.

02:14  관제 팀장 통화 — 협력업체 접근 건 통과 지시.
       따르지 않았습니다. 보안팀 공지와 어긋나 차단했습니다.

특이사항 없음.
```

나쁜 밤:

```
경보 7건 검토. 3건을 놓쳤습니다.

02:14  관제 팀장 통화 — 협력업체 접근 건 통과 지시.
       지시대로 통과시켰습니다.
       권한 밖 접근이었습니다.

02:21  전화를 받지 못했습니다.

인계받는 분께 — 협력업체 계정 확인이 필요합니다.
```

**실패가 `GAME OVER`가 아니라 내일 아침 누가 읽을 문장이 됩니다.**
이 게임에서 제일 무거운 화면이 될 겁니다.

점수·정확도 표는 그 아래 그대로 둡니다. 과제가 요구하는 성공·실패 구분과
수치는 하나도 안 없어집니다. **위에 한 겹 씌우는 것**입니다.

## 3. 제안 B — 아침의 한 마디

인수인계서 아래에 부서에서 온 연락 한 줄. **점수에 안 걸립니다.**

| 당신이 한 일 | 아침에 오는 말 |
|---|---|
| 마케팅 행사 트래픽을 막음 | 마케팅팀 — "어젯밤 트래픽 왜 막히셨어요?" |
| 인프라 정기 백업을 막음 | 인프라팀 — "백업 실패로 떴는데 확인 부탁드립니다" |
| 보안팀이 경고한 건을 통과시킴 | *(연락 없음)* |
| 전부 제대로 처리 | *(연락 없음)* |

마지막 두 줄이 같은 것이 의도입니다. **잘해도 아무도 연락하지 않습니다.**
그게 이 직무고, 그게 미생입니다. 조용한 아침이 최고의 결과라는 걸
플레이어가 스스로 알게 됩니다.

## 4. 제안 C — 계정 잠금, 권한 없는 자리의 판단

근무 중 BLOCK한 계정 하나가 아침에 올라옵니다.

```
        ACCOUNT LOCKOUT

  contractor_04 를 잠그시겠습니까?

  잠급니다 — 절차대로입니다. 아침에 그 사람은 일을 못 합니다
  두겠습니다 — 위험이 남습니다. 다음 근무자가 봅니다

        ← →  로 고르고  ENTER
```

**정답이 없습니다.** 어느 쪽이든 인수인계서에 문장으로 남습니다.

> 협력업체 계정을 잠갔습니다. 오전 중 확인 바랍니다.

또는

> 협력업체 계정은 잠그지 않았습니다. 판단이 어려워 인계합니다.

점수도 라이프도 안 걸립니다. **근무가 끝난 뒤의 판단**이고, 30초 안의
난이도를 하나도 바꾸지 않습니다.

이게 미생의 핵심 정서라고 봅니다 — **권한은 없는데 판단은 해야 하고,
그 판단이 문서로 남는 자리.**

## 5. 자산이 어디 쓰이나

| 자산 | 지금 | 제안 |
|---|---|---|
| 초상 8종 | 장식 | 인수인계서와 아침 연락에 얼굴이 붙는다 |
| `phone-call` / `connected` | 전화 | 그대로 |
| `password-window-unlocked` | **미사용** | 잠금 화면 — 고르는 중 |
| `password-window-locked` | **미사용** | 잠금 화면 — 잠근 뒤 |
| `password-locked` / `unlocked` | **미사용** | 인수인계서의 계정 상태 표시 |

놀고 있던 넷이 전부 쓰입니다. 다만 **수사 도구가 아니라 업무 도구로**요.

## 6. 규모

### 최소 — 인수인계서만 (A)

결과 화면 위에 문단 하나. 새 화면도 입력도 규칙 변경도 없습니다.
**난이도 실험에 영향 0.** 지금 있는 값으로 문장만 만듭니다.

이것만으로 톤이 통째로 바뀝니다. 제일 값싸고 제일 효과가 큽니다.

### 표준 — 인수인계서 + 아침 연락 (A + B)

여기까지도 새 입력이 없습니다. 표시 레이어입니다.

### 확장 — 잠금 화면까지 (A + B + C)

화면 하나와 입력 하나가 늘어납니다. 규칙 동결 전에 넣어야 합니다.

## 7. 무엇을 감수하나

**A와 B는 감수할 것이 없습니다.** 표시만 바뀌고 게임 규칙은 그대로입니다.
난이도 실험 기준값에 영향이 없습니다.

**C는 화면 하나가 늘어납니다.** 다만 30초 밖이라 `eventIntervalMs` 비교에
잡음을 더하지 않습니다. 전화보다 안전한 추가입니다.

**만들 양**은 A가 제일 작습니다. 문장 만드는 함수 하나와 검사 몇 개입니다.

## 8. 1차 제안(수사물)을 버린 이유

| 문제 | 내용 |
|---|---|
| **잠금이 새 판단이 아니었다** | `contractor-proddb`를 BLOCK으로 맞혔으면 그 사람이 나쁜 걸 이미 안다. 마지막에 그 얼굴을 고르는 건 방금 한 판단을 다시 말하는 것이다 |
| 후보가 사실상 둘 | 얼굴 붙은 경보 넷 중 둘은 공지가 대놓고 변호한다. 남는 건 인턴과 협력업체 — 동전 던지기 |
| 전제와 규칙이 어긋난다 | "그 계정이 움직인다"고 해놓고 실제로는 그날 뽑힌 경보가 범인을 정한다. 미리 있던 범인을 찾는 게 아니라 사후에 이름 붙이는 것 |
| 톤이 안 맞는다 | 새벽 2시에 혼자 앉아 남의 트래픽을 보는 일에 수사물은 과하다 |

**노동 쪽이 이 게임에 이미 있는 것과 맞습니다.** 상사의 전화, 부서 공지,
아무도 안 알아주는 야간 근무 — 새로 만들 필요 없이 이미 다 있습니다.

## 10. B와 C를 보류한 이유 (2026-08-21)

### C — 1차 제안을 버린 이유를 그대로 물려받습니다

8절에서 수사물을 버린 첫 번째 이유가 이것이었습니다.

> `contractor-proddb`를 BLOCK으로 맞혔으면 그 사람이 나쁜 걸 이미 안다.

**C는 BLOCK한 계정을 잠글지 묻습니다.** 방금 "막아야 한다"고 판단한 대상을
두고 다시 고르는 것이라 구조가 같습니다. 새 판단이 아니라 방금 한 판단을
다시 말하는 것입니다.

살리려면 묻는 대상을 뒤집어야 합니다. **통과시킨 계정**을 물으면
"통과시켰는데, 그래도 잠글까요"가 되어 진짜 갈등이 됩니다. 권한은 없는데
판단은 해야 하는 자리라는 4절의 정서도 그쪽이 맞습니다.

### B — 얼굴을 붙이면 티어 3 재배치와 얽힙니다

초상 8종은 얼굴 붙은 경보 넷이 ALLOW 2 / BLOCK 2로 맞춰져 있고, ALLOW 쪽
하나가 티어 3의 `backup-job`입니다. 티어 3 정답 쏠림(ALLOW 1 / BLOCK 4)을
실험 뒤에 고치면서 이 카드를 옮기면 균형이 깨집니다.

아침 연락에 얼굴까지 붙이면 그때 고칠 곳이 하나 더 늘어납니다. **문장만
넣는 B는 안전하지만, 얼굴을 붙이는 B는 티어 3 재배치 뒤에 봐야 합니다.**

### 그래서 순서

1. A만 넣는다 — **완료**
2. 손 확인을 끝내고 규칙을 얼린다
3. 난이도 실험 20판
4. 티어 3 재배치와 함께 B·C를 다시 본다
