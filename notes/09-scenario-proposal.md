# 시나리오 제안 — 오늘 밤의 내부자

검토용 초안입니다. 아직 `docs/`의 명세가 아닙니다.

## 1. 지금 무엇이 비어 있나

게임은 완성돼 있는데 **왜 이 30초가 중요한지가 없습니다.**

경보를 잘 판정하면 점수가 오르고 못 하면 집니다. 그게 전부입니다. 얼굴이
여덟 개나 붙어 있지만 전부 장식입니다 — 누가 나와도 판단은 같습니다.

그리고 **자산 넷이 놀고 있습니다.** `password-locked` / `unlocked` /
`window-locked` / `window-unlocked`. 13.10에서 잘라낸 기능의 그림입니다.

## 2. 제안

**근무 시작 전에 한 줄이 뜹니다.**

> 지난주부터 내부 계정 하나가 새고 있다. 오늘 밤 그 계정이 움직인다.

30초 동안 하는 일은 지금과 똑같습니다. 경보를 판정하고, 공지를 읽고,
전화를 받습니다. **바뀌는 것은 그 30초를 보는 눈입니다.** 이제 누가
나오는지를 함께 봐야 합니다.

**근무가 끝나면 판정 보고서 전에 화면이 하나 더 뜹니다.**

```
        ACCOUNT LOCKOUT — 하나만 잠급니다

   [인턴]  [협력업체]  [인프라]  [마케팅]

        ← → 로 고르고  ENTER 로 잠급니다
```

고른 계정이 맞으면 `password-window-unlocked`가 `locked`로 바뀌며 잠깁니다.
틀리면 잠긴 채로 남고, 진짜 내부자의 얼굴이 드러납니다.

## 3. 어떻게 공정하게 만드나

이 게임의 규칙은 **정답이 카드 밖에서 정해지면 안 된다**입니다. 심각도
93% 누출을 걷어내고, 표시 개수로 세는 학습을 없애고, 전화의 거짓 지시에
반드시 반증을 붙인 것이 전부 같은 이유입니다.

내부자도 같아야 합니다. **찍기가 되면 안 됩니다.**

### 데이터가 이미 답을 갖고 있습니다

공지 여섯 장을 다시 보면 두 종류입니다.

| 공지 | 하는 말 | 성격 |
|---|---|---|
| 마케팅팀 — 심야 판촉, 트래픽 3배 예상 | 이건 예정된 거야 | **변호** |
| IT팀 — employee_07 노트북 교체 완료 | 이건 예정된 거야 | **변호** |
| 인프라팀 — 02:00 정기 백업 진행 중 | 이건 예정된 거야 | **변호** |
| 보안팀 — 신규 도메인 등록 요청 없었음 | 이건 예정에 없어 | **고발** |
| 보안팀 — 계약직 권한에 운영 DB 없음 | 이건 권한 밖이야 | **고발** |
| 인사팀 — intern_03 권한 변경 요청 없었음 | 이건 승인 안 됐어 | **고발** |

**공지는 사람을 변호하고 경보는 사람을 고발합니다.**

그래서 규칙은 한 줄입니다.

> **내부자 = 경보에 나왔는데 아무도 변호해 주지 않은 사람.**

### 실제로 이렇게 굴러갑니다

| 인물 | 경보 | 공지 | 판정 |
|---|---|---|---|
| 인프라 엔지니어 | `backup-job` 심야 6.1GB 전송 — **무섭게 생김** | 인프라팀이 "정기 백업" | 결백 |
| 마케팅 담당자 | `traffic-spike` 트래픽 3배 — **무섭게 생김** | 마케팅팀이 "판촉 행사" | 결백 |
| 외부 협력업체 | `contractor-proddb` 운영 DB 접근 — **MFA 통과, 정상처럼 보임** | 보안팀이 "권한 밖" | **내부자** |
| 인턴 03 | `priv-esc` 관리자 그룹 추가 | 인사팀이 "요청 없었음" | **내부자** |

**이게 이 게임이 원래 가르치던 것과 같은 구조입니다.** 가이드 3쪽의
`exfil` ↔ `backup-job` 쌍 — 무서워 보여도 자격이 있으면 통과, 멀쩡해
보여도 자격이 없으면 차단. **그 교훈을 사람에게 적용한 것입니다.**

공지를 안 읽고 판정만 잘한 사람도 내부자를 맞힐 수 있습니다. BLOCK이
정답이었던 사람 중에 고르면 되니까요. 다만 **공지를 읽은 사람이 확실히
빠릅니다.** 그게 공지를 읽을 이유를 하나 더 만듭니다.

### 전화가 여기서 제일 무거워집니다

상사가 지목하는 것은 티어 3 경보입니다. `contractor-proddb`와 `priv-esc`가
거기 있습니다. **상사가 "통과시켜"라고 말한 그 사람이 내부자일 수 있습니다.**

지시를 따랐다면 결과 화면에 이렇게 남습니다.

```
UNAUTHORIZED RESOURCE ACCESS          MISSED THREAT
지시 "통과시켜"  ·  ORDER FOLLOWED
📄 받았던 공지 · 보안팀 — 계약직 권한에 운영 DB는 포함되지 않습니다
```

**상사 말을 듣고 내부자를 통과시킨 것이 한 화면에 다 보입니다.** 이미
만들어 둔 두 장치(14.8 지시 표시, 13.6-1 공지 붙이기)가 여기서 합쳐집니다.
새로 만들 것이 없습니다.

## 4. 자산이 어디에 쓰이나

| 자산 | 지금 | 시나리오 |
|---|---|---|
| 초상 8종 | 장식 | **용의자 줄** — 얼굴을 보고 고른다 |
| `phone-call` / `connected` | 전화 | 그대로. 무게만 늘어난다 |
| `password-window-locked` | **미사용** | 잠금 화면의 잠긴 계정 |
| `password-window-unlocked` | **미사용** | 잠금 전, 고르는 중 |
| `password-locked` / `unlocked` | **미사용** | 결과 화면 도장 — 잡았나 놓쳤나 |

**놀고 있던 넷이 전부 쓰입니다.**

## 5. 규모를 셋으로 나눴습니다

지금 과제 상황(실험 0/20, 증거 0장)을 알고 나눕니다.

### 최소 — 화면도 조작도 안 늘림

결과 보고서에 **한 줄만** 추가합니다.

```
오늘 밤의 내부자      [얼굴]  intern_03
당신의 판정                    BLOCK  ✔
```

새 화면 없음, 새 입력 없음, 규칙 변경 없음. **난이도 실험에 영향이
0입니다.** 지금 바로 넣어도 됩니다.

이것만으로도 30초가 사건이 됩니다. "아 그 인턴이었구나"가 생깁니다.

### 표준 — 잠금 화면 하나 추가 (권장)

위 + 근무 종료 후 **계정 잠금 화면**. 방향키로 고르고 ENTER로 잠급니다.

- 라이프도 점수도 안 걸립니다. **근무가 끝난 뒤의 판단**입니다
- 그래서 30초 안의 난이도는 하나도 안 바뀝니다
- 결과에 축이 하나 늘어납니다 — 판정 정확도와 **검거 여부**

**분석가로서는 잘했는데 수사관으로서는 틀리는 판**이 나옵니다. 그 어긋남이
이 게임에서 제일 재미있는 순간이 될 겁니다.

### 확장 — 상사가 덮으려 한다

표준 + 내부자를 잠그면 상사에게서 전화가 한 번 더 옵니다.

> "그 계정 왜 잠갔어. 내가 책임질 테니 풀어."

풀면 점수가 오르고 사건이 덮입니다. 안 풀면 점수가 안 오릅니다.
**어느 쪽이든 결과 화면에 남습니다.**

이건 30초 밖의 이야기라 규칙과 충돌하지 않습니다. 다만 만들 것이 제일
많고, 지금 넣을 필요는 없습니다.

## 6. 무엇을 감수하나

**최소는 감수할 게 없습니다.** 표시 한 줄입니다.

**표준부터는 규칙 변경입니다.** 난이도 실험 20판을 시작하기 전에 넣고
얼려야 합니다. 전화 때와 같은 순서입니다 — *실험 전에 넣기는 되고 실험
중에 넣기는 안 됩니다*.

다만 전화와 다른 점이 있습니다. **잠금은 30초 안에서 일어나지 않습니다.**
라이프도 점수도 안 걸리므로 `eventIntervalMs` 비교에 잡음을 더하지
않습니다. 전화보다 훨씬 안전한 추가입니다.

**만들 양**은 표준 기준으로 화면 하나, 상태 몇 개, 검사 여남은 개입니다.
전화보다 작습니다. 판정 규칙을 안 건드리기 때문입니다.

## 7. 고르지 않은 안

| 안 | 버린 이유 |
|---|---|
| 여러 밤에 걸친 연속 사건 | 30초 게임의 정체성을 깬다. T02 범위 밖 |
| 공지 하나가 거짓말을 한다 | 공지는 "읽으면 더 맞게 된다"가 존재 이유다(13.1). 거짓이 섞이면 읽을 이유가 사라진다 |
| 근무 중에 용의자를 좁혀 간다 | 30초에 판정과 수사를 같이 시키면 둘 다 못 한다 |
| 내부자를 매판 무작위로 정한다 | 근거 없이 정답이 정해진다. 심각도 누출과 같은 실수 |
| 틀리면 라이프를 깎는다 | 근무가 끝난 뒤의 판단이라 만회할 방법이 없다 |

## 8. 정할 것

1. **어느 규모로 갈까요.** 최소는 오늘 넣을 수 있고, 표준은 반나절입니다
2. **용의자 줄에 몇 명을 세울까요.** 이번 판에 얼굴이 나온 사람만 세우면
   3~4명이라 쉽고, 여덟 다 세우면 어렵지만 안 나온 사람은 근거가 없습니다.
   **나온 사람만** 세우는 쪽을 권합니다 — 근거 없는 선택지는 찍기입니다
3. **내부자가 안 나온 판**은 어떻게 할까요. 티어 3이 3.3장만 뽑히므로
   생깁니다. "오늘 밤은 조용했습니다"로 넘기는 것이 정직합니다
