# 검증과 제출 준비 계획

## 검증 안내서 초안

### 어디로 가나요

`https://myeongjundev.github.io/mini-game/`

> 배포 완료 후 실제 주소로 확인해 확정합니다. 최신 브라우저에서 열면 되고 설치나 로그인은 필요 없습니다.

### 무엇을 하나요

1. 첫 화면에서 규칙과 조작(`A` 허용 / `D` 차단)을 확인하고 `START SHIFT`를 누릅니다.
2. 30초 동안 올라오는 보안 이벤트를 읽고 정상이면 `A`, 위협이면 `D`를 누릅니다. 마우스 버튼도 됩니다.
3. 근무 중 사내 공지(`MEMO`)가 뜨면 `SPACE`로 닫습니다. 닫아도 화면 옆 로그에 남아 다시 읽을 수 있습니다.
4. 근무 후반에 상사의 전화가 오면 `↑`로 받거나 `↓`로 미룹니다. **받지 않고 벨이 끝나면 라이프가 하나 줄어듭니다.**
5. 한 판이 끝나면 결과 화면에서 `RETURN TO READY`를 누르고, 화면 위 음소거와 움직임 줄이기 버튼을 눌러 즉시 반영되는지 확인합니다.

### 무엇이 보이면 통과인가요

- `TIME`·`SCORE`·`SECURITY`(하트 3개)·`COMBO`가 화면에 계속 보입니다.
- 키를 한 번 누르면 판정이 정확히 한 번 일어납니다.
- 30초를 버티면 `SHIFT COMPLETE`, 라이프를 다 잃으면 `SECURITY LOST`가 뜹니다.
- 결과 화면 맨 위에 `INCIDENT HANDOVER`가 있고, 그 판에 실제로 있었던 일이 문장으로 적힙니다.
- 다시 시작하면 시간 30초·라이프 3·점수 0·콤보 0으로 돌아가고, 최고 점수는 남아 있습니다.
- 음소거와 움직임 줄이기가 누른 즉시 바뀝니다. 움직임 줄이기를 켜면 화면 흔들림이 사라지고 테두리 색 변화로 대체됩니다.
- 결과 화면에서 오탐(False Positive)과 미탐(Missed Threat)이 각각 다른 색으로 따로 집계됩니다.

### 안 될 때

- **화면이 흰색으로만 보입니다** → 주소 끝의 `/mini-game/`까지 정확히 입력했는지 확인하고 강력 새로고침(`Ctrl` + `Shift` + `R`)을 눌러 주세요.
- **키가 안 먹습니다** → 게임 화면을 한 번 클릭해 포커스를 준 뒤 다시 눌러 주세요. 다른 탭으로 이동하면 자동으로 일시정지되며, 돌아온 뒤 `RESUME`을 눌러야 진행됩니다.
- **판정 버튼이 흐리게 바뀌고 안 눌립니다** → 공지나 전화가 떠 있는 동안에는 판정이 막힙니다. 그동안 그 경보의 제한 시간도 멈추므로 손해는 없습니다. 공지는 `SPACE`, 전화는 `↑` 또는 `↓`로 넘기면 다시 눌립니다.
- **소리가 안 납니다** → 첫 로드는 음소거 상태로 시작합니다. 화면 위 음소거 버튼을 눌러 켜 주세요.
- **점수가 이상하게 남아 있습니다** → 최고 점수는 의도적으로 보존됩니다. 초기화하려면 브라우저 사이트 데이터를 지워 주세요.
- 그래도 안 되면 다른 최신 브라우저에서 한 번 더 열어 봐 주세요.

## AI 사용 기록 3줄 초안

> 아래는 현재까지의 사실 기준 초안입니다. 구현이 끝난 뒤 실제 작업 내용과 다시 대조해 확정합니다.

**1줄 — AI에게 맡긴 일**
게임 아이디어 후보 비교, 경보 데이터셋과 문서 구조 초안, 픽셀 아이콘 그리드 초안, 검사표 설계, 반복적인 구현 작업을 AI에게 맡겼다.

**2줄 — 내가 판단한 일**
후보 5개 중 SOC SHIFT:30을 직접 골랐고, 30초 안에 이해되도록 관제 업무를 ALLOW/BLOCK 두 조작으로 줄였다. 오탐과 미탐을 별개의 실패로 설계하고 각각 앰버와 레드로 색을 나눠, 차단이 공짜가 아니라는 점이 화면에 드러나게 했다. 난이도 상수도 이 게임에 실제로 존재하는 변수인 등장 간격으로 직접 정했다.

**3줄 — AI 말을 안 들은 일**
AI는 배포가 단순하다는 이유로 순수 HTML·CSS·JS를 권했지만, 이후 ALEPH 과제로 확장할 것을 고려해 Vite + React + TypeScript를 직접 선택했다. 문서 폴더를 문서 전용으로 두라는 제안도 받아들이지 않고 프로젝트 루트로 승격시켰다. 도트 표현은 AI 제안대로 글자에서 빼되, 완전히 버리라는 방향은 따르지 않고 아이콘에 남겼다. 초기 아이디어였던 실시간 네트워크 시뮬레이션과 LLM 연동 기능은 과제 범위를 넘어서므로 넣지 않았다.
