# 과제 요구사항 기준선

## 과제

- 제목: 내가 설계한 미니게임
- 결과물: 브라우저에서 실행되는 짧은 게임
- 장르: 자유

## 확정 사항

| 항목 | 값 |
|---|---|
| 게임 제목 | SOC SHIFT:30 |
| 한 줄 정의 | 30초 동안 SOC 분석가가 되어 보안 이벤트를 ALLOW / BLOCK으로 판단해 네트워크를 지키는 게임 |
| 장르 | 보안 판단 게임. 같은 사실이 맥락에 따라 다른 답을 내므로 퀴즈가 아니다 |
| 표현 | 정보는 모노스페이스, 도트는 아이콘에만. NIGHT SHIFT 콘솔 톤 |
| 구현 | Vite + React 18 + TypeScript, 정적 배포 |
| 프로젝트 루트 | `aleph-t02-soc-shift30/` |
| 난이도 실험 상수 | `eventIntervalMs` (기준 3000 → 비교 2000) |

도트를 글자에 쓰지 않기로 한 이유: 이 게임은 3초 안에 사실 4개를 읽어야 하는 **읽기 게임**이라, 픽셀 폰트를 쓰면 판단 실패가 "내가 못 읽어서"가 된다. 도트는 카테고리 아이콘, 라이프, 판정 마크, 토글, 등급 도장에만 넣는다.

상세 명세는 `aleph-t02-soc-shift30/BUILD_ORDER.md`와 `docs/`에 있다.

## 필수 동작

| 요구사항 | 구현 | 증거 | 남은 것 |
|---|---|---|---|
| 규칙·조작·상태 표시 | **완료** 로비에 조작키·HOW TO PLAY 6쪽 | 없음 | 캡처 |
| 조작 1회 → 상태 변화 1회 | **완료** `event.repeat` 가드 + 중복 판정 잠금, 검사로 확인 | 없음 | 캡처 |
| 성공·실패 구분 | **완료** SUCCESS / FAILURE | 없음 | 캡처 |
| 다시 시작 | **완료** 검사로 확인 | 없음 | 캡처 |
| 효과 선택권 | **완료** 음소거 5단계 + 움직임 줄이기, 즉시 반영 | 없음 | 캡처 |
| 두 해상도 | **완료** 1366·1920에서 가로 넘침 0 실측 | 없음 | 캡처 |
| 안정성 | **부분** 연속 입력·10분 실행 미실행 | 일부 | 사람 검사 + 캡처 |
| 난이도 조정 | **미통과** 전·후 20판 비교를 하지 않기로 결정(08-21) | 없음 | 없음 — `notes/11-final-audit.md` D절 |

| 공개 안전 | **완료** 개인정보·비밀값 0건 | 없음 | 캡처 |

**열한 개 중 열은 만들기가 끝났고 캡처만 남았습니다.** 코드를 더 쓰는 일이
아닙니다.

**난이도 조정 하나는 미통과입니다.** 전·후 20판 비교를 하지 않기로
결정했습니다(08-21). 게임의 제한시간 3000ms는 확정이고 바꾸지 않지만,
그것을 고른 근거가 A/B 기록이 아니라 체감 판단이라 이 칸은 채워지지
않습니다. 판정 전문은 `11-final-audit.md` D절에 있습니다.
