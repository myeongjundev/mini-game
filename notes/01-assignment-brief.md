# 과제 요구사항 기준선

## 과제

- 제목: 내가 설계한 미니게임
- 결과물: 브라우저에서 실행되는 짧은 게임
- 장르: 자유
- 표현: 도트 스타일 예정, 비트 수준은 게임 콘셉트 확정 후 결정

## 필수 동작

| 요구사항 | 구현 기준 | 필요한 증거 | 현재 상태 |
|---|---|---|---|
| 규칙·조작·상태 표시 | 공개 첫 화면에서 15초 안에 이해 가능 | 공개 화면 캡처 | 미정 |
| 조작 1회 → 상태 변화 1회 | 키 또는 클릭 1회가 중복 없이 반영 | 조작 전·후 화면 또는 기록 | 미정 |
| 성공·실패 구분 | 한 판이 반드시 둘 중 하나로 종료 | 성공·실패 화면 | 미정 |
| 다시 시작 | 현재 점수·시간·생명·게임 오브젝트 초기화 | 재시작 전·후 기록 | 미정 |
| 효과 선택권 | 음소거 또는 움직임 줄이기가 즉시 반영 | 설정 전·후 화면 | 미정 |
| 두 해상도 | 1366×768, 1920×1080에서 잘림·가로 넘침 없음 | 해상도별 캡처와 overflow 기록 | 미정 |
| 안정성 | 연속 입력·포커스 이탈·일시정지·10분 실행 통과 | 검사표 | 미정 |
| 난이도 조정 | 전 10회, 상수 1개 변경, 후 10회 | CSV와 최종값 판단 | 미정 |
| 저장·복구 | 현재 판 초기화, 선택 기록 유지, 손상값 기본 복구 | 저장 검사표 | 미정 |
| 콘솔 | 빨간 오류 0건 | 콘솔 화면 | 미정 |
| 공개 안전 | 개인정보·비밀값 0건 | 정적 검사 기록 | 미정 |
