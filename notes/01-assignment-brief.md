# 과제 요구사항 기준선

## 과제

- 제목: 내가 설계한 미니게임
- 결과물: 브라우저에서 실행되는 짧은 게임
- 장르: 자유

## 확정 사항

| 항목 | 값 |
|---|---|
| 게임 제목 | SOC SHIFT:30 |
| 한 줄 정의 | 30초 동안 SOC 분석가가 되어 보안 이벤트를 ALLOW / BLOCK으로 판단해 네트워크를 지키는 게임 |
| 장르 | 보안 판단 게임. 같은 사실이 맥락에 따라 다른 답을 내므로 퀴즈가 아니다 |
| 표현 | 정보는 모노스페이스, 도트는 아이콘에만. NIGHT SHIFT 콘솔 톤 |
| 구현 | Vite + React 18 + TypeScript, 정적 배포 |
| 프로젝트 루트 | `aleph-t02-soc-shift30/` |
| 난이도 실험 상수 | `eventIntervalMs` (기준 3000 → 비교 2000) |

도트를 글자에 쓰지 않기로 한 이유: 이 게임은 3초 안에 사실 4개를 읽어야 하는 **읽기 게임**이라, 픽셀 폰트를 쓰면 판단 실패가 "내가 못 읽어서"가 된다. 도트는 카테고리 아이콘, 라이프, 판정 마크, 토글, 등급 도장에만 넣는다.

상세 명세는 `aleph-t02-soc-shift30/BUILD_ORDER.md`와 `docs/`에 있다.
