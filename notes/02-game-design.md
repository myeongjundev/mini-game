# 게임 설계 결정서

- 장르:
- 도트 표현 수준: 8비트 / 16비트 / 32비트
- 화면 분위기와 색상:
- 핵심 조작: 키보드 / 마우스 / 둘 다

## 규칙 한 문장

> 플레이어는 ______를 조작해 ______를 하면 성공하고, ______가 되면 실패한다.

## 한 판 흐름

```text
READY → PLAYING → SUCCESS 또는 FAILURE → RESTART → READY
                    ↕
                  PAUSED
```

## 상태별 화면

| 상태 | 화면에 보여줄 내용 | 허용 입력 |
|---|---|---|
| READY | 규칙, 조작, 난이도, 시작 버튼 | 시작 |
| PLAYING | 현재 점수·시간·생명 등 현재 판 값 | 핵심 조작, 일시정지 |
| PAUSED | 일시정지 이유와 재개 방법 | 재개, 다시 시작 |
| SUCCESS | 성공 이유와 최종 기록 | 다시 시작 |
| FAILURE | 실패 이유와 최종 기록 | 다시 시작 |
