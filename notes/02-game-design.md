# 게임 설계 결정서

## 결정 완료

- 게임 제목: **SOC SHIFT:30**
- 장르: 보안 판단 게임
- 도트 표현 수준: 16비트 감성. 단 **아이콘에만** 적용하고 정보 텍스트는 모노스페이스
- 화면 분위기와 색상: NIGHT SHIFT 콘솔. 뉴트럴 다크 `#0A0C10` + 시안 `#3FC8E0` / 앰버 `#F0A93B` / 레드 `#E2564D`
- 핵심 조작: 둘 다. `A`·`←` = ALLOW, `D`·`→` = BLOCK, `P`·`Esc` = 일시정지, 마우스 버튼 병행

## 규칙 한 문장

> 플레이어는 **키보드 또는 마우스**를 조작해 **30초 동안 들어오는 보안 이벤트를 ALLOW / BLOCK으로 판단하며 라이프를 지키면** 성공하고, **오판으로 라이프 3개를 모두 잃으면** 실패한다.

## 두 종류의 실패

이 게임의 핵심이다. 실패가 한 가지가 아니다.

| 실수 | 이름 | 결과 | 색 |
|---|---|---|---|
| 정상 트래픽 + BLOCK | False Positive | 서비스가 죽는다 | 앰버 |
| 위협 트래픽 + ALLOW | Missed Threat | 침해가 일어난다 | 레드 |

둘 다 라이프 -1이지만 결과 화면에서 **다른 색 막대**로 집계된다. 과차단형인지 과허용형인지가 한눈에 보인다.

## 한 판 흐름

```text
READY → PLAYING → SUCCESS 또는 FAILURE → RESTART → READY
                    ↕
                  PAUSED
```

## 상태별 화면

| 상태 | 화면에 보여줄 내용 | 허용 입력 |
|---|---|---|
| READY | 규칙, 조작, 난이도, 시작 버튼 | 시작 |
| PLAYING | 현재 점수·시간·생명 등 현재 판 값 | 핵심 조작, 일시정지 |
| PAUSED | 일시정지 이유와 재개 방법 | 재개, 다시 시작 |
| SUCCESS | 성공 이유와 최종 기록 | 다시 시작 |
| FAILURE | 실패 이유와 최종 기록 | 다시 시작 |

## 초기화와 보존

- 새 판에서 초기화: 남은 시간 30초, 라이프 3, 점수 0, 콤보 0, 현재 경보, 판정 통계 전부
- 다시 접속해도 보존: 최고 점수, 음소거 설정, 움직임 줄이기 설정
- 저장값이 없거나 손상됐을 때 기본값: `bestScore` 0, 음소거 꺼짐, 움직임 줄이기 꺼짐
- **현재 판 상태는 저장하지 않는다.** 새로 접속하면 항상 READY에서 시작한다

저장 키는 `socshift30:v1`. 필드 단위로 검증해 깨진 항목만 기본값으로 대체한다.
상세는 `aleph-t02-soc-shift30/docs/STORAGE_AND_RECOVERY.md`.

## 효과와 선택권

- 효과가 발생할 사건: 정답 판정, 오판 판정, 크리티컬 경보 등장, 라이프 감소
- 기본 효과: 경보가 아래→위 슬라이드 인. 판정 시 ALLOW는 왼쪽 / BLOCK은 오른쪽으로 슬라이드 아웃. 오답 시 짧은 화면 흔들림. 짧은 톤 사운드
- 움직임 줄이기 시 대체 효과: 이동과 흔들림을 전부 제거하고 **테두리 색 플래시 0.2초**로 대체. 정보 손실 0
- 음소거 시: 사운드만 제거. 판정 결과는 아이콘과 텍스트로 그대로 전달
- **첫 로드는 음소거 ON.** 브라우저 자동재생 정책에 안전하고 채점자가 갑자기 소리를 듣지 않는다
- 두 설정 모두 **즉시** 반영된다. 다음 판까지 기다리지 않는다

## 난이도 상수

후보(속도 / 등장 간격 / 제한 시간 / 판정 범위) 중 **등장 간격**을 선택했다.

| 구분 | 상수 | 값 |
|---|---|---|
| 변경 전 | `eventIntervalMs` | 1400 |
| 변경 후 | `eventIntervalMs` | 1100 |

선택 이유: 30초 고정 게임에서 제한 시간은 건드릴 수 없고, 이 게임에는 이동 속도와 판정 범위가 없다. 등장 간격은 **읽고 판단할 시간**을 직접 줄이므로 난이도와 인과가 명확하고, 오탐·미탐 수치에 미치는 영향을 그대로 관찰할 수 있다.

이 상수는 `src/game/config.ts` 한 곳에만 둔다. 전·후 실험에서 다른 값은 바꾸지 않는다.
