## 주요 결정과 이유

과제의 "AI 말을 안 들은 일"과 직결되는 판단들입니다.
정리본은 `aleph-t02-soc-shift30/docs/AI_DECISION_LOG.md`에 있습니다.

### 스택 — Vite + React + TypeScript
AI는 배포가 단순하다는 이유로 순수 정적 파일을 권했지만, 이후 ALEPH 과제
확장을 고려해 React를 직접 선택했습니다. 문서 폴더도 프로젝트 루트로 승격시켰습니다.

### 백엔드를 T02 범위 밖으로
Spring은 GitHub Pages에 올릴 수 없고, 별도 서버가 죽으면 "공개 주소에서 실행"
기준 전체가 흔들립니다. 이후 Incident Journal 과제로 분리했습니다.

### 도트는 글자에서 빼고 아이콘에만
1.4초에 사실 4줄을 읽는 게임이라 픽셀 폰트를 쓰면 판단 실패가 폰트 탓이 됩니다.
카테고리·라이프·판정·토글·등급에만 도트를 남겨 정체성은 지켰습니다.

### 색을 오탐·미탐 2축으로
BLOCK 버튼을 빨강이 아니라 앰버로 뒀습니다. 차단이 공짜가 아니라는 감각을
버튼 단계에서 주고, 그 앰버가 결과 화면의 오탐 막대로 이어집니다.

### 미판정을 별도 실패로 (C안)
제한시간 내 무입력 시 라이프 -1, 콤보 0, 점수 0. `reviewed`는 올리지 않아
Accuracy가 "검토한 것 중 맞힌 비율"로 유지됩니다.
아무것도 안 하면 반드시 지므로 30초의 긴장이 유지됩니다.

### 난이도 상수는 등장 간격
제한 시간 30초는 정체성이라 못 건드리고, 속도·판정 범위는 이 게임에 없습니다.
등장 간격만 "읽고 판단할 시간"을 직접 줄여 인과가 명확합니다.

### 저장소를 public으로
private 저장소는 무료 플랜에서 GitHub Pages를 못 씁니다. 포트폴리오가 목적이라
공개가 오히려 자산이라 판단해 전환했습니다.

## 가이드를 4쪽으로 나눈 이유

동기들 피드백이 "설명이 부족하다"가 아니라 **"내용을 이해 못 하겠다"**였습니다.
분량 문제가 아니라 가르치는 방식의 문제였습니다.

경보 15개를 다시 보니 정답을 가르는 것은 거의 항상 **행위가 아니라 자격**이었습니다.

| 쌍 | 같은 것 | 다른 것 | 정답 |
|---|---|---|---|
| `exfil` / `backup-job` | 새벽 시간, 몇 GB 전송, 표시 붙음 | 목적지가 Unknown Host / Registered Backup Server | BLOCK / ALLOW |
| `ssh-brute` / `typo-login` | 로그인 실패 다수 | 출처가 Unknown / 등록 기기이고 결국 성공 | BLOCK / ALLOW |
| `contractor-proddb` | MFA 통과 | 계약직의 운영 DB 첫 접근 | BLOCK |

특히 `exfil`과 `backup-job`은 **거의 같은 카드인데 목적지 한 줄에서 갈립니다.**
이 한 쌍을 3쪽에 그대로 보여주는 것이 설명 열 줄보다 낫다고 판단했습니다.
두 카드는 `ALERTS`에서 직접 읽으므로 데이터가 바뀌면 가이드도 함께 바뀝니다.

4쪽에는 `f8d3772`에서 사라졌던 오탐·미탐 구분을 되살렸습니다. 앰버와 빨강
2축 설계가 결과 화면의 막대와 이어집니다.

### 구현에서 한 번 틀린 것

처음에는 제목·본문·쪽 넘김을 한 덩어리로 스크롤시켰습니다. 그랬더니 내용이

이 구조가 아니면 가이드 자체를 못 읽습니다.

## 검증 환경의 한계
