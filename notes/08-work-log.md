## 주요 결정과 이유

과제의 "AI 말을 안 들은 일"과 직결되는 판단들입니다.
정리본은 `aleph-t02-soc-shift30/docs/AI_DECISION_LOG.md`에 있습니다.

### 스택 — Vite + React + TypeScript
AI는 배포가 단순하다는 이유로 순수 정적 파일을 권했지만, 이후 ALEPH 과제
확장을 고려해 React를 직접 선택했습니다. 문서 폴더도 프로젝트 루트로 승격시켰습니다.

### 백엔드를 T02 범위 밖으로
Spring은 GitHub Pages에 올릴 수 없고, 별도 서버가 죽으면 "공개 주소에서 실행"
기준 전체가 흔들립니다. 이후 Incident Journal 과제로 분리했습니다.

### 도트는 글자에서 빼고 아이콘에만
1.4초에 사실 4줄을 읽는 게임이라 픽셀 폰트를 쓰면 판단 실패가 폰트 탓이 됩니다.
카테고리·라이프·판정·토글·등급에만 도트를 남겨 정체성은 지켰습니다.

### 색을 오탐·미탐 2축으로
BLOCK 버튼을 빨강이 아니라 앰버로 뒀습니다. 차단이 공짜가 아니라는 감각을
버튼 단계에서 주고, 그 앰버가 결과 화면의 오탐 막대로 이어집니다.

### 미판정을 별도 실패로 (C안)
제한시간 내 무입력 시 라이프 -1, 콤보 0, 점수 0. `reviewed`는 올리지 않아
Accuracy가 "검토한 것 중 맞힌 비율"로 유지됩니다.
아무것도 안 하면 반드시 지므로 30초의 긴장이 유지됩니다.

### 난이도 상수는 등장 간격
제한 시간 30초는 정체성이라 못 건드리고, 속도·판정 범위는 이 게임에 없습니다.
등장 간격만 "읽고 판단할 시간"을 직접 줄여 인과가 명확합니다.

### 저장소를 public으로
private 저장소는 무료 플랜에서 GitHub Pages를 못 씁니다. 포트폴리오가 목적이라
공개가 오히려 자산이라 판단해 전환했습니다.

## 리뷰 지적 사항 (인트로·로비, 미해결)

판정: **수정 필요**

### 치명적
- **C-1** 판단 가이드 회귀 — 로비 개편에서 조작키 안내와 예시 카드 2장이 사라짐.
  MENU 화면에 조작키가 한 글자도 없고 HOW TO PLAY를 눌러야 나옴.
  `notes/01` 필수 동작 1행, `GAME_SPEC` 12절 위반.
  `global.css`의 `.ready-example*` 규칙 12개가 렌더링 없이 잔존.

### 중요
- **M-1** 11px 미만 글자 — `.crt-display { clamp(7px, 0.82vw, 13px) }`.
  실측 1280×720에서 헤더·푸터 **7.56px**, 1920에서 **9.36px**.
  SOUND·REDUCE MOTION은 조작 버튼인데 7.56px. 641~1340px 구간이 사각지대.
- **M-2** 미판정 플래시가 이전 경보의 결정적 항목 표시 — `App.tsx:229`에
  `lastDecisiveFactRef` 갱신 누락. **수정 완료**, 회귀 테스트는 미작성.
- **M-3** `aria-live="polite"`가 버튼 5개를 포함한 컨테이너 전체에 걸림.
- **M-5** PNG 2.15MB — 배포 산출물의 92%.

### 경미
- **m-1** LOBBY 진입 시 포커스가 body에 남음.
- **m-3** 배경 이미지에 START SHIFT / HOW TO PLAY / SHIFT RECORD가 구워져 있음.
  라이브 오버레이와 중복이라 메뉴가 바뀌면 그림이 거짓말을 함.
  실제 상표 `MultiSync 14`, `WINDOWS NT SECURITY`도 읽힘.

## 검증 환경의 한계

이어받는 사람이 같은 벽에 부딪히지 않도록 적습니다.

- **브라우저에서 rAF가 돌지 않습니다.** 자동화 도구의 브라우저 패널이
  표시되지 않아 `document.hidden === true`입니다. 그래서 타이머·미판정·
  재시작 20회는 **자동 검증이 불가능**하며 사람이 직접 봐야 합니다.
- **인트로 실시간 관측 불가.** 스크립트 주입이 페이지 로드 8초 뒤에 도달해
  3.1초 인트로가 이미 끝나 있습니다. 단위 테스트가 fake timer로 대신 검증합니다.
- **이미지 도구 없음.** PIL·ImageMagick·sharp 모두 미설치.
