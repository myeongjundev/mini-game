# PC 숨은 검사표

| 1366×768 | 조작 영역 잘림과 가로 넘침이 없다 | 미실행 | 미정 | |

| 창·탭 포커스 이탈 | 자동 일시정지되어 불리하게 진행되지 않는다 | 미실행 | 미정 | |
