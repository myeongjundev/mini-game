# 저장과 복구 계획

## 값 분리

| 구분 | 값 | 새 판 | 새로 접속 | 저장 |
|---|---|---|---|---|
| 현재 판 | 점수·남은 시간·라이프·콤보·현재 경보 | 초기화 | 복원하지 않음 | **안 함** |
| 개인 기록 | 최고 점수 | 유지 | 유지 | 함 |
| 접근성 설정 | 음소거, 움직임 줄이기 | 유지 | 유지 | 함 |

저장 키는 `socshift30:v1`. 저장 형식은 아래와 같다.

```json
{ "v": 1, "bestScore": 0, "mute": false, "reduceMotion": false }
```

기본값: `bestScore` 0, `mute` false, `reduceMotion` false.
`bestScore`는 0 이상 999999 이하의 유한한 정수만 허용한다.

**현재 판 상태는 어떤 경우에도 저장하지 않는다.** 진행 중이던 판이 복원되면 "다시 시작하면 초기화된다"는 요구를 만족할 수 없기 때문이다.

구현 명세는 `aleph-t02-soc-shift30/docs/STORAGE_AND_RECOVERY.md`에 있다.

## 저장 형식 원칙

- 버전 필드를 둡니다.
- 숫자는 유한한 값인지와 허용 범위를 검사합니다.
- 예상하지 않은 필드는 사용하지 않습니다.
- 읽기·파싱 오류는 잡고 기본값으로 복구합니다.
- 저장 실패가 게임 실행을 막지 않게 합니다.

## 복구 검사표

콘솔에서 값을 심고 새로고침하는 방식으로 검사합니다.

```js
localStorage.setItem('socshift30:v1', '<검사값>')
```

| 저장 상태 | 심을 값 | 기대 결과 | 실제 결과 | 증거 |
|---|---|---|---|---|
| 저장값 없음 | (키 삭제) | 기본값으로 실행 | 미실행 | |
| 빈 문자열 | `` | 기본값으로 실행 | 미실행 | |
| 글자만 있는 값 | `abc` | 기본값으로 실행 | 미실행 | |
| JSON 문법 오류 | `{"bestScore":` | 기본값으로 실행 | 미실행 | |
| 필수 항목 누락 | `{}` | 누락 항목만 기본값 적용 | 미실행 | |
| 잘못된 자료형 | `{"v":1,"bestScore":"높음"}` | 해당 항목 기본값 적용 | 미실행 | |
| 음수·비정상적으로 큰 숫자 | `{"v":1,"bestScore":-5}` | 허용 범위의 기본값 적용 | 미실행 | |
| 정상값 | `{"v":1,"bestScore":2140,"mute":true,"reduceMotion":false}` | 보존값만 정상 복원 | 미실행 | |

**모든 경우에 콘솔 빨간 오류가 0건이어야 합니다.** 복구했다는 사실이 오류로 보고되면 안 됩니다.
