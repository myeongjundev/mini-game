# 저장과 복구 계획

## 값 분리

| 구분 | 값 | 새 판 | 새로 접속 |
|---|---|---|---|
| 현재 판 | 점수·시간·생명·위치·오브젝트 | 초기화 | 복원하지 않음 |
| 개인 기록 | 최고점수 등 확정한 값 | 유지 | 유지 |
| 접근성 설정 | 움직임 줄이기 또는 음소거 | 유지 여부 결정 | 유지 여부 결정 |

## 저장 형식 원칙

- 버전 필드를 둡니다.
- 숫자는 유한한 값인지와 허용 범위를 검사합니다.
- 예상하지 않은 필드는 사용하지 않습니다.
- 읽기·파싱 오류는 잡고 기본값으로 복구합니다.
- 저장 실패가 게임 실행을 막지 않게 합니다.

## 복구 검사표

| 저장 상태 | 기대 결과 | 실제 결과 | 증거 |
|---|---|---|---|
| 저장값 없음 | 기본값으로 실행 | 미실행 | |
| 빈 문자열 | 기본값으로 실행 | 미실행 | |
| 글자만 있는 값 | 기본값으로 실행 | 미실행 | |
| JSON 문법 오류 | 기본값으로 실행 | 미실행 | |
| 필수 항목 누락 | 누락 항목만 기본값 적용 | 미실행 | |
| 잘못된 자료형 | 해당 항목 기본값 적용 | 미실행 | |
| 음수·비정상적으로 큰 숫자 | 허용 범위의 기본값 적용 | 미실행 | |
| 정상값 | 보존값만 정상 복원 | 미실행 | |
