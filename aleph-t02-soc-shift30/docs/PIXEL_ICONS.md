# PIXEL ICONS — SOC SHIFT:30

`src/game/data/pixelArt.ts`의 원본이다.
아이콘을 고칠 때는 **이 문서의 그리드를 먼저 고치고** 코드를 따라 바꾼다.

## 형식

`.` = 투명, `#` = 채움. 한 아이콘은 문자열 배열 하나다.
렌더링 규칙은 `BUILD_ORDER.md` 6절을 따른다. `rect`만 쓰고 색은 `currentColor`가 정한다.

## 검수 기준

- **흑백 테스트**: 색을 모두 제거하고 실루엣만으로 구별되어야 한다.
- 정수 배율(2x, 3x)만. 소수 배율은 픽셀을 뭉갠다.
- 해상도가 바뀌어도 표시 크기를 바꾸지 않는다.
