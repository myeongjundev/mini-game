# QA CHECKLIST — SOC SHIFT:30

과제의 숨은 검사 범주를 **구현 전에** 설계해 둔 문서다.
실행 전에 `기대`를 먼저 확정하고, 실행 후 `실제`와 `수정`을 채운다.
결과는 `mini-game/notes/03-test-matrix.md`에도 반영하며, 제출 증거는 `notes/` 쪽을 원본으로 쓴다.

검사 환경: 데스크톱 브라우저, 콘솔 열어둔 상태.

### 12.7이 자동 검사로 안 잡히는 이유

하단 버튼 층 `.lobby-modal-commands`가 `inset: 0`이라 모달 전체를 덮는다.
자리만 잡는 층인데 나중에 온 이 층이 닫기 버튼 위에 얹혀 **마우스 클릭을
가로챘다.** 우측 상단 닫기가 마우스로 눌리지 않는 상태였다.

**검사는 통과하고 있었다.** `.click()`은 히트 테스트를 건너뛰고 요소에 바로
이벤트를 보내기 때문이다. 브라우저에서 `elementFromPoint`로 재서야 나왔다.

jsdom은 스타일시트를 적용하지도, 화면을 합성하지도 않아 `pointer-events`를
확인할 수 없다. **겹침이 걸린 조작은 사람이나 브라우저가 봐야 한다.**
`docs/TROUBLESHOOTING.md`의 "검증이 실물보다 관대하다"와 같은 계열이다.

### CRT 안이라는 제한을 걷어냈다

인계서(`prompts/04`)는 모달을 CRT 유리 안에 두라고 했고 처음에는 그렇게
만들었다. **플레이해보니 본문이 118px밖에 안 나와 가이드가 계속 잘렸다.**

그림 속 모니터는 로비 화면의 무대이지 대화상자의 경계가 아니다.
모달을 씬 전체로 옮겼다. 대신 씬 밖으로는 나가지 않는다.

| | 유리 안 (이전) | 씬 기준 (지금) |
