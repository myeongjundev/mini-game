# 상사의 전화 — 도트 일러스트 발주서

**상태: 아직 입력하지 않음.** 아래 블록 중 하나를 골라 그대로 붙여넣으세요.

산출물 형식이 두 가지입니다. **결과가 다르니 먼저 고르세요.**

| | 만드는 것 | 용량 | 팔레트·크기 | 나중에 고칠 때 |
|---|---|---|---|---|
| **A** | SVG 도트 (코드) | **0KB** | 토큰을 자동으로 따라감 | 좌표만 고치면 됨 |
| **B** | WebP 래스터 (그림 파일) | 20~40KB | 그림에 구워짐 | 다시 뽑아야 함 |

A안은 이 프로젝트가 원래 도트를 다루던 방식과 같습니다. 아이콘 20개가 전부
좌표 배열이고 색은 `currentColor`가 정합니다. 일러스트도 같은 원리로 키우면
됩니다 — 크기가 커지니 문자열 그리드 대신 `rect` 좌표 목록이 될 뿐입니다.

B안은 배경 `lobby-office-blank`와 같은 계열입니다. 표현의 폭이 넓은 대신
용량과 팔레트를 손으로 관리해야 하고, 색 토큰이 바뀌면 그림이 따라오지
않습니다. 배경에 UI와 상표가 구워져 아직 미해결로 남은 것이 그 비용입니다.

## 왜 지금 그림만인가

상사의 전화는 `GAME_SPEC` 13.10절에서 **의도적으로 뺀** 방해 요소입니다.

> 무시할 수 있게 하고 점점 거슬리게 만드는 설계가 필요하다.
> 비용의 타이밍을 플레이어가 정하는 형태라 메모보다 복잡하다

13.10은 "메모를 먼저 넣고 반응을 본 뒤 결정한다"로 닫혀 있고, **그 반응을 아직
안 봤습니다.** 지금은 난이도 실험 20판을 앞두고 규칙 동결 중이라, 방해 요소를
하나 더 넣으면 실험 기록이 무효가 됩니다. 그림만 먼저 받아둡니다.

## 고정 수치 — 두 안 공통

전부 코드에서 확인한 값입니다.

| 항목 | 값 | 근거 |
|---|---|---|
| 표시 박스 | **670 × 330px** | 셸 `--card-w` 720 − 패딩 48 − 테두리 2 = 670. `.alert-card`의 `min-height: 330px` |
| 저작 해상도 | **335 × 165px** | 정확히 2배로 표시한다. `PIXEL_ICONS` 검수 기준 "정수 배율만. 소수 배율은 픽셀을 뭉갠다" |
| 배경 | **투명** | `.memo-toast`처럼 `--panel` 패널 위에 얹힌다 |
| 팔레트 | 아래 6색만 | `src/styles/tokens.css` |

```
--bg     #0A0C10   가장 어두운 바탕
--panel  #12161D   패널
--line   #232B36   경계선
--amber  #F0A93B   경고·전화 벨
--red    #E2564D   실패·위험
--green  #6FCF6B   정상
```

**`DESIGN_TOKENS` 8절 금지 목록이 그림에도 그대로 적용됩니다.**

- 그라디언트, 글로우, 네온, 블러 → **평면 음영만.** 배경 그림도 평면 음영이다
- 색만으로 구분되는 상태 → 벨이 울리는 것을 색으로만 표현하지 마라. 형태로도 보여라
- 안티앨리어싱 금지. 1px 단위로만 존재한다

## A안 — SVG 도트로 갈 때

```text
SOC SHIFT:30에 쓸 도트 일러스트를 SVG 컴포넌트로 그려라.
래스터 이미지 파일을 만들지 마라. 좌표로 그린다.

먼저 읽어라.
  src/components/PixelIcon.tsx   기존 도트 렌더링 방식
  src/game/data/pixelArt.ts      승인된 그리드 20개. 화풍의 기준이다
  src/styles/tokens.css          색 토큰
  docs/DESIGN_TOKENS.md 8절      하지 말 것
  docs/GAME_SPEC.md 13절         방해 요소 MEMO. 전화는 13.10에 있다

────────────────────────────────
그릴 것

새벽 SOC 근무 중 걸려오는 상사의 전화. 유선 전화기 한 대가 울리는 장면이다.
경보 카드를 덮는 오버레이의 그림 부분이고, 글자는 이 그림에 넣지 마라.
글자는 전부 HTML이다. 배경 그림에 UI를 구워넣었다가 되돌린 적이 있다.

────────────────────────────────
형식 — 어기면 못 쓴다

- 저작 좌표계 335 × 165. viewBox="0 0 335 165" 하나로 끝낸다
- 표시는 670 × 330. 정확히 2배다. 소수 배율은 픽셀을 뭉갠다
- rect만 써라. path, circle, ellipse, filter, gradient 전부 쓰지 마라
- rect의 x y width height는 전부 정수여야 한다
- 색은 tokens.css의 CSS 변수로만 쓴다. hex를 컴포넌트에 하드코딩하지 마라
  (DESIGN_TOKENS 8절 "컴포넌트 안 하드코딩 hex" 금지)
- 그라디언트·글로우·네온·블러 금지. 평면 음영만 쓴다
- 배경을 칠하지 마라. 투명해야 패널 위에 얹힌다

────────────────────────────────
읽혀야 하는 것

1. 670×330으로 놓고 **1초 안에** "전화가 울린다"가 읽혀야 한다.
   경보 판정 중에 끼어드는 그림이라 들여다볼 시간이 없다
2. 흑백으로 만들어도 무엇인지 알아야 한다.
   PIXEL_ICONS 검수 기준 1번이 이 저장소의 흑백 테스트다
3. 벨이 울리는 것을 앰버 색으로만 나타내지 마라.
   형태로도 보여야 한다 (진동선, 흔들린 수화기 등)

────────────────────────────────
하지 말 것

- public/ 에 파일을 만들지 마라. PNG·JPG·WebP·독립 SVG 파일 전부 금지다
- 애니메이션을 넣지 마라. Reduce Motion 처리를 따로 해야 하고
  아직 규칙이 없다. 정지 화면 한 장이다
- App.tsx, machine.ts, useGameLoop.ts 를 건드리지 마라
- 게임 규칙을 제안하거나 GAME_SPEC을 고치지 마라.
  난이도 실험 20판을 앞두고 규칙이 동결돼 있다
- 그림에 글자를 넣지 마라

────────────────────────────────
산출 형식

1. 먼저 구도 3안을 글로 설명해라. 정면 전화기 / 책상 위 비스듬히 /
   수화기 클로즈업 처럼 뿌리가 달라야 한다. 각 안마다
   "670×330에서 1초 안에 읽히는 근거"를 한 줄로 적어라
2. 내가 하나를 고르면 그때 SVG 컴포넌트를 써라.
   src/components/PhoneArt.tsx 한 파일이다
3. rect 개수를 보고해라. 200개를 넘으면 형태를 단순화해라

**고르기 전에 코드를 쓰지 마라.** PIXEL_ICONS 4절 규칙이다.
"그리드 승인 없이 컴포넌트 코드를 먼저 쓰지 않는다."
```

## B안 — 래스터로 갈 때

```text
SOC SHIFT:30에 쓸 도트 일러스트를 그려서 저장소에 넣어라.

먼저 읽어라.
  src/game/data/pixelArt.ts      승인된 그리드 20개. 화풍의 기준이다
  src/styles/tokens.css          색 토큰
  docs/DESIGN_TOKENS.md 8절      하지 말 것
  docs/DESIGN_TOKENS.md 9절      배경 그림 변환 절차. 그대로 따른다

────────────────────────────────
그릴 것

2D 픽셀 아트. 335×165 픽셀. 투명 배경.

새벽 보안관제실 책상 위에서 울리는 유선 전화기 한 대.
평면 음영만 쓰고 그라디언트·글로우·네온·블러를 쓰지 마라.
안티앨리어싱 없이 1픽셀 단위의 선명한 도트로 그려라.

색은 다음 6가지만 쓴다.
  #0A0C10  #12161D  #232B36  #F0A93B  #E2564D  #6FCF6B

전화기 본체는 어두운 회색 계열, 울림 표시는 #F0A93B.
울림을 색으로만 나타내지 마라. 형태로도 보여라 (진동선, 흔들린 수화기 등).

글자·숫자·로고를 그림에 넣지 마라. 글자는 전부 HTML이다.
실제 제조사 상표를 넣지 마라.

────────────────────────────────
넣을 곳과 용량

- public/phone-call.webp 한 파일이다. 다른 파일을 만들지 마라
- **40KB를 넘기지 마라.** 지금 배포 산출물 전체가 349KB이고
  배경 WebP가 1180px에 147KB다. 리뷰 M-5에서 PNG 2.15MB가
  산출물의 92%를 먹어 다시 뽑은 적이 있다
- 변환은 DESIGN_TOKENS 9절 절차를 따르고 alphaQuality를 100으로 둬라
- **변환 후 sharp를 반드시 지워라.** 20MB 네이티브 모듈인데 lint·build·test
  어디에도 안 쓰여서, 남으면 CI의 npm ci가 매번 내려받는다
- 최종 파일의 크기와 픽셀 치수를 보고해라

────────────────────────────────
하지 말 것

- 화면에 붙이지 마라. 컴포넌트·CSS를 만들지 마라. 어디에 뜨는지 아직 안 정했다
- App.tsx, machine.ts, useGameLoop.ts 를 건드리지 마라
- 게임 규칙을 제안하거나 GAME_SPEC을 고치지 마라.
  난이도 실험 20판을 앞두고 규칙이 동결돼 있다
- 애니메이션 프레임을 여러 장 만들지 마라. 정지 화면 한 장이다

────────────────────────────────
내기 전에

구도 3안을 먼저 글로 설명해라. 정면 전화기 / 책상 위 비스듬히 /
수화기 클로즈업 처럼 뿌리가 달라야 한다. 각 안마다
"670×330에서 1초 안에 읽히는 근거"를 한 줄로 적어라.
내가 하나를 고른 뒤에 그려라.
```

**상표 두 줄이 중요합니다.** 배경 그림에서 실제 상표(`MultiSync 14`,
`WINDOWS NT SECURITY`)가 읽혀 아직 미해결로 남아 있습니다.

### 변환 절차

`DESIGN_TOKENS` 9절의 배경 변환과 같습니다.

```bash
npm i -D sharp
node --input-type=module -e "
import sharp from 'sharp'
const out = await sharp('원본.png').resize({ width: 335 })
  .webp({ quality: 92, effort: 6, alphaQuality: 100 })
  .toFile('public/phone-call.webp')
console.log(out.width + 'x' + out.height, (out.size / 1024).toFixed(1) + ' KB')
"
npm uninstall sharp
```

**변환 후 sharp를 반드시 지우세요.** 20MB 네이티브 모듈인데 lint·build·test
어디에도 안 쓰여서, 남으면 CI의 `npm ci`가 매번 내려받습니다.

표시할 때 `image-rendering: pixelated`를 넣어야 2배로 키워도 뭉개지지 않습니다.
